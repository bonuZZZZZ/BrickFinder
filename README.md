# BrickFinder Android — бесплатная основа (0.5)

**Статус:** исходный проект Android. APK в архиве отсутствует. Сборка GitHub Actions подготовлена, но не запускалась и не проверена в этом окружении. Это не финальный агрегатор цен.

## Реализовано
- Android UI: поиск по названию/артикулу, выбранный город Тверь.
- Выбор фотографии из галереи с `ACTION_GET_CONTENT`.
- Бесплатное распознавание текста на устройстве Google ML Kit, приоритет фотозапроса над текстом.
- Автоматический поиск по распознанному артикулу.
- Отображение **только конкретных товарных карточек** и цен, если возвращены HTTPS-сервером в формате предыдущего BrickFinder v0.3.
- При неподключённом источнике цен честно показывает состояние, не выдумывает товары и не выдаёт ссылки на поисковую выдачу.

## Пока отсутствует
- Подтверждённый бесплатный агрегатор прямых карточек и актуальных цен всех маркетплейсов.
- Распознавание собранного набора без текста методом visual matching.
- Автоматическая проверка доставки до Твери и цены после авторизации/скидок.
- Постоянный бесплатный HTTPS-сервер.

## Как получить APK бесплатно без Android Studio
1. Зарегистрируйся на https://github.com (если аккаунта нет).
2. Создай **private** или **public** репозиторий. Для public убедись, что не публикуешь секреты. При приватном репозитории действуют бесплатные квоты GitHub Actions.
3. Загрузи **содержимое этой папки**, включая скрытую `.github/workflows/android.yml`, в корень репозитория.
4. Открой **Actions → Build BrickFinder APK → Run workflow** (или сделай push в `main`).
5. После успешной сборки открой завершившийся workflow, скачай артефакт `BrickFinder-Android-APK`, распакуй ZIP и установи `app-debug.apk`.
6. Если сборка выдаст ошибку, отправь лог: конфигурация Gradle предоставлена как исходник, без локальной проверки Android SDK.

Технический запуск с установленными Java 17, Android SDK platform 35 и Gradle 8.9: `gradle :app:assembleDebug`.

## Подключение цен
В приложении есть поле **HTTPS-адрес сервера**. Оно принимает ссылку на развернутый API из BrickFinder v0.3, который предоставляет `/api/search?q=...&city=Тверь&analog_first=true` и массив `items` с `title`, `url`, `shop`, `price`. Предыдущий сервер без `SERPAPI_KEY` не умеет получать результаты; этот APK его не заменяет. Хранить ключи следует только на сервере, не в приложении.

**Без действительного источника товаров полнофункционального сравнения цен не будет.**
